## 📌 About the Project

An AI-powered software maintenance system that analyzes uploaded software projects and provides intelligent maintenance insights.

The user uploads a project ZIP file, and the system automatically analyzes the source code, detects programming languages, calculates software metrics, evaluates complexity and quality, predicts maintenance effort, estimates maintenance cost, calculates maintenance risk, detects hotspots and anomalies, and provides AI-based recommendations.
